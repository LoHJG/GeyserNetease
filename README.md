# GeyserNetease 扩展

## 这是什么？

GeyserNetease 是一个 **Geyser 扩展**，它能让 **网易版 Minecraft（中国版基岩版）** 的玩家连接到使用 Geyser 的服务器。

简单来说：如果你有一个 Java 版 Minecraft 服务器，并且用 Geyser 让基岩版玩家也能进来玩，那么装了这个扩展之后，**网易版的玩家也能加入你的服务器了**。

---

## 为什么需要它？

网易版 Minecraft 虽然也是基岩版，但它和国际版基岩版有一些区别：
- 使用不同的网络协议版本
- 有自己的账号验证系统
- 包含一些网易特有的游戏内容

默认的 Geyser 只能连接国际版基岩版玩家，网易版玩家是进不来的。装了这个扩展之后，你的服务器就能同时支持：
- ✅ Java 版玩家
- ✅ 国际版基岩版玩家
- ✅ **网易版基岩版玩家**（本扩展新增）

---

## 下载前你需要知道的

### 前置要求
1. 你必须已经安装了 **Geyser**（这是 Geyser 的扩展，不能单独使用）
2. 你的 Geyser 版本需要支持扩展 API 2.12.0 或更高（即 Geyser 2.12.0 及以上）

### 配置说明
安装后，扩展会生成一个配置文件 `config.yml`。**默认值就是已经过真实网易客户端（1.21.124 / 协议 860）验证可用的组合**，通常不需要改：

#### 1. 只允许网易客户端 (`only-netease-clients`)
- `false`（默认）：国际版和网易版都能进
- `true`：只允许网易版玩家进入，国际版玩家会被拒绝

#### 2. 方块网络 ID 哈希 (`block-network-ids-hashed`)
- `true`（默认，**必须保持**）：把方块 ID 改写成网易客户端期望的哈希值
- `false`：发送 Geyser 的调色板下标 —— 老客户端会**方块全部错乱**，仅供排查使用

#### 3. StartGame 方块属性表 (`clear-start-game-block-properties`)
- `true`（默认）：删掉 Geyser 按新版构造的 105 条数据驱动方块定义，老客户端解析不了会崩
- `false`：保留；若客户端启动即崩再打开

#### 4. 永不发送的包 (`dropped-packets`)
- 留空或 `[]`（默认）：全部发送
- 列出包名：只丢这些包

> ⚠️ 早期版本曾默认丢弃 `CreativeContentPacket`，这会让玩家**一打开创造背包就闪退**。现在这个包会正常发送，里面的方块 ID 会被自动翻译成哈希值。

#### 5. 调试模式 (`debug-mode`)
- `false`（默认）：正常运行。排查所需的诊断信息（方块 ID 实测值、创造列表重写统计等）**一直在普通输出里**，无需打开
- `true`：额外追踪每一个 Bedrock 收发包（`IN`/`OUT`），**日志量极大**，仅深度排查时开启

### 换 jar 后必须完整重启服务器
`/geyser reload` **不会重新加载扩展 jar**（Geyser 只在启动时从磁盘读取扩展）。改配置用 reload 即可，换 jar 必须重启。

### 支持的版本
支持多个网易版协议版本，包括 v630、v686、v766、v819、v860 等。

## 常见问题

**Q：装了这个会影响国际版玩家吗？**
A：不会。默认配置下，国际版和网易版玩家都能正常游玩，互不影响。

**Q：网易玩家进来后能玩所有内容吗？**
A：大部分内容都可以正常玩。但网易版特有的一些内容（比如特定皮肤、商城物品）可能无法完全兼容。

**Q：这个扩展是官方的吗？**
A：不是。这是社区开发者制作的第三方扩展。
